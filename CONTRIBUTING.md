# Contributing

Thanks for taking an interest in this project.

## Issues and bug reports

Open a GitHub issue with what you expected, what happened, and your platform/environment (Claude Code, ChatGPT, OpenAI Codex, etc.). This is the fastest way to get something looked at.

## Pull requests

We review pull requests case by case. Before opening one for anything beyond a small fix (typo, doc clarification, obvious bug), please open an issue first to discuss the change — this is a small project maintained without a dedicated review team, and unsolicited larger changes may sit unreviewed for a while or not be merged.

**We do not yet have a formal Contributor License Agreement or Developer Certificate of Origin process.** Until we do, by submitting a pull request you confirm the contribution is your own original work (or you otherwise have the right to submit it), and you agree it will be distributed under this repository's MIT license, same as the rest of the codebase. We may ask for a `Signed-off-by` line (Developer Certificate of Origin, see [developercertificate.org](https://developercertificate.org/)) on larger contributions as this process matures.

## What we're unlikely to accept

- Changes that weaken or remove the safety checks and disclaimers described in `SKILL.md` and `SECURITY.md` — these exist deliberately, see this repo's `SECURITY.md` for why.
- Changes that add credential storage, telemetry, or network calls to WiselyWise infrastructure — this skill is deliberately built to hold no credentials and phone home to nowhere.
